01Introduction to WPF

Windows Presentation Foundation (WPF) is Microsoft's UI framework for building Windows desktop applications with rich graphics, data binding, and XAML-based UI.

WPF vs PyQt Quick Comparison

ConceptPyQtWPF
UI DefinitionPython code or Qt Designer (.ui)XAML (declarative XML)
UI ElementsWidgets (QWidget, QPushButton)Controls (Button, TextBox)
Event HandlingSignals & SlotsEvents & Commands (MVVM)
Data BindingManual or Qt Model/ViewBuilt-in powerful binding
StylingQSS (Qt Style Sheets)Styles & Templates (XAML)
LayoutQVBoxLayout, QGridLayoutStackPanel, Grid, DockPanel
ArchitectureMVC or customMVVM (recommended)

03XAML Basics

XAML (eXtensible Application Markup Language) defines UI declaratively. Each element maps to a .NET class.

XAML Syntax 
<!-- Element = Class instance -->
<Button>Click Me</Button>

<!-- Attribute = Property -->
<Button Content="Click Me" 
        Width="100" 
        Height="30"/>

<!-- Property Element Syntax -->
<Button>
    <Button.Content>
        <StackPanel Orientation="Horizontal">
            <Image Source="icon.png" Width="16"/>
            <TextBlock Text="Save"/>
        </StackPanel>
    </Button.Content>
</Button>
Equivalent C# 
// Simple button
var button = new Button 
{ 
    Content = "Click Me",
    Width = 100,
    Height = 30
};

// Button with complex content
var panel = new StackPanel 
{ 
    Orientation = Orientation.Horizontal 
};
panel.Children.Add(new Image 
{ 
    Source = new BitmapImage(
        new Uri("icon.png")),
    Width = 16 
});
panel.Children.Add(new TextBlock 
{ 
    Text = "Save" 
});
var btn = new Button { Content = panel };

06Data Binding

Data binding automatically synchronizes UI and data. This is WPF's killer feature!

📝 PyQt vs WPF

In PyQt: widget.setText(value) manually. In WPF: bind once, changes propagate automatically!

Binding Syntax 
<!-- Simple binding -->
<TextBox Text="{Binding UserName}"/>

<!-- Two-way (default for TextBox) -->
<TextBox Text="{Binding UserName, Mode=TwoWay}"/>

<!-- Update on every keystroke -->
<TextBox Text="{Binding SearchText, 
    UpdateSourceTrigger=PropertyChanged}"/>

<!-- String formatting -->
<TextBlock Text="{Binding Price, StringFormat=C2}"/>
<TextBlock Text="{Binding Date, StringFormat=yyyy-MM-dd}"/>

<!-- Fallback -->
<TextBlock Text="{Binding Name, FallbackValue='Unknown'}"/>
INotifyPropertyChanged 
public class ViewModelBase : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler? 
        PropertyChanged;
    
    protected void OnPropertyChanged(
        [CallerMemberName] string? name = null)
    {
        PropertyChanged?.Invoke(this, 
            new PropertyChangedEventArgs(name));
    }
    
    protected bool SetProperty<T>(
        ref T field, T value,
        [CallerMemberName] string? name = null)
    {
        if (Equals(field, value)) return false;
        field = value;
        OnPropertyChanged(name);
        return true;
    }
}
ViewModel with Properties 
public class MainViewModel : ViewModelBase
{
    private string _userName = "";
    public string UserName
    {
        get => _userName;
        set => SetProperty(ref _userName, value);
    }
    
    private bool _isLoading;
    public bool IsLoading
    {
        get => _isLoading;
        set => SetProperty(ref _isLoading, value);
    }
    
    // ObservableCollection auto-notifies on add/remove
    public ObservableCollection<User> Users { get; } = new();
}

09Commands

Commands handle user actions (button clicks) without code-behind, keeping logic in ViewModels.

RelayCommand 
public class RelayCommand : ICommand
{
    private readonly Action _execute;
    private readonly Func<bool>? _canExecute;
    
    public RelayCommand(Action execute, 
        Func<bool>? canExecute = null)
    {
        _execute = execute;
        _canExecute = canExecute;
    }
    
    public event EventHandler? CanExecuteChanged
    {
        add => CommandManager.RequerySuggested += value;
        remove => CommandManager.RequerySuggested -= value;
    }
    
    public bool CanExecute(object? p) => 
        _canExecute?.Invoke() ?? true;
    
    public void Execute(object? p) => _execute();
}
Using Commands in ViewModel 
public class MainViewModel : ViewModelBase
{
    public ICommand SaveCommand { get; }
    public ICommand DeleteCommand { get; }
    
    public MainViewModel()
    {
        SaveCommand = new RelayCommand(
            Save, 
            () => !string.IsNullOrEmpty(UserName)
        );
        
        DeleteCommand = new RelayCommand<User>(
            user => Users.Remove(user)
        );
    }
    
    private void Save()
    {
        // Save logic
    }
}

10Value Converters

Converters transform data between binding source and target.

BoolToVisibility Converter 
public class BoolToVisibilityConverter : IValueConverter
{
    public object Convert(object value, Type targetType,
        object parameter, CultureInfo culture)
    {
        return value is bool b && b 
            ? Visibility.Visible 
            : Visibility.Collapsed;
    }
    
    public object ConvertBack(object value, Type targetType,
        object parameter, CultureInfo culture)
    {
        return value is Visibility v 
            && v == Visibility.Visible;
    }
}
Using Converters 
<!-- Register converter -->
<Window.Resources>
    <local:BoolToVisibilityConverter 
        x:Key="BoolToVis"/>
</Window.Resources>

<!-- Use in binding -->
<ProgressBar Visibility="{Binding IsLoading, 
    Converter={StaticResource BoolToVis}}"/>

<TextBlock Visibility="{Binding HasError, 
    Converter={StaticResource BoolToVis}}"
           Text="Error occurred!"
           Foreground="Red"/>

12Input Validation

INotifyDataErrorInfo 
public class ValidatingViewModel : ViewModelBase, 
    INotifyDataErrorInfo
{
    private readonly Dictionary<string, List<string>> 
        _errors = new();
    
    public bool HasErrors => _errors.Any();
    
    public event EventHandler<DataErrorsChangedEventArgs>? 
        ErrorsChanged;
    
    public IEnumerable GetErrors(string? name)
    {
        if (name != null && _errors.ContainsKey(name))
            return _errors[name];
        return Enumerable.Empty<string>();
    }
    
    private string _email = "";
    public string Email
    {
        get => _email;
        set
        {
            SetProperty(ref _email, value);
            ValidateEmail();
        }
    }
    
    private void ValidateEmail()
    {
        _errors.Remove(nameof(Email));
        if (!Email.Contains("@"))
            _errors[nameof(Email)] = 
                new List<string> { "Invalid email" };
    }
}
Validation Error Style 
<TextBox Text="{Binding Email, 
    ValidatesOnNotifyDataErrors=True,
    UpdateSourceTrigger=PropertyChanged}"/>

13Async Operations

Async Command 
public class AsyncRelayCommand : ICommand
{
    private readonly Func<Task> _execute;
    private bool _isExecuting;
    
    public AsyncRelayCommand(Func<Task> execute) => _execute = execute;
    
    public bool CanExecute(object? p) => !_isExecuting;
    
    public async void Execute(object? p)
    {
        _isExecuting = true;
        try { await _execute(); }
        finally { _isExecuting = false; }
    }
    
    public event EventHandler? CanExecuteChanged;
}

// Usage in ViewModel
public ICommand LoadCommand => new AsyncRelayCommand(async () =>
{
    IsLoading = true;
    var data = await _service.GetDataAsync();
    Items.Clear();
    foreach (var item in data) Items.Add(item);
    IsLoading = false;
});

15Best Practices

💡 WPF Best Practices

1. Use MVVM - Keep logic in ViewModels, not code-behind
2. Use ObservableCollection - For lists that update UI
3. Use ICommand - For button actions, not Click events
4. Use Converters - For data transformation in bindings
5. Use Resource Dictionaries - Organize styles/templates
6. Use async/await - Keep UI responsive
7. Validate with INotifyDataErrorInfo - Built-in validation
8. Use Dependency Injection - For testable ViewModels
